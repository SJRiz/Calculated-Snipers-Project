# About
Note: This project was made a couple years back using replit's IDE, and I only recently have pushed it to Github. I will be redoing this project once I finish other ones I am working on.
Welcome to Graph Sniping (or Calculated Snipers)! This project/game was made using the PyGame library in Python, and is a unique math-driven game where you must type an equation to hit a target.
Each level gets progressively harder, with more randomly-generated objects blocking the path to the target, meaning you must be creative with the equations you type!

# Rules & How to play:
The equation format is similar to desmos.
Example: sin(cos(x+2)*(x^2))
You must type the equation in the console. All the code is in main.py, and it relies on the assets folder to display images/content
